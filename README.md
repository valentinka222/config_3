# УВМ: ассемблер и интерпретатор (вариант 23)

## 1. Общее описание

Проект содержит ассемблер и интерпретатор для УВМ.
Ассемблер читает программу в формате JSON и переводит ее в команды УВМ.
Интерпретатор выполняет ассемблированную программу и сохраняет дамп памяти в XML.

## 2. Описание функций и настроек

### Аргументы ассемблера:

`Assembler <программа.json> <результат.bin> [--test]`

- `программа.json`-путь к исходному файлу с программой,
- `результат.json`-путь к двоичному файлу-результату,
- `--test`-режим тестирования: выводит поля и значения каждой команды.

### Язык ассемблера (JSON)

Программа - массив объектов, каждый объект - одна команда.
Поле `op` задает команду, остальные поля - операнды.
Код команды подставляется автоматически.

- `load_const` (A=142, 4 байта): поля `b` - константа 0-2047, `c` - адрес регистра 0-127.
  Регистр[c] = b.
- `read_mem` (A=75, 3 байта): поля `b` и `c` - адреса регистров 0-127.
  Регистр[c] = память[регистр[b]].
- `write_mem` (A=17, 5 байт): поля `b` - смещение 0-2047, `c` и `d` - адреса регистров 0-127.
  Память[регистр[c] + b] = регистр[d].
- `popcnt` (A=161, 5 байт): поля `b` - смещение 0-2047, `c` и `d` - адреса регистров 0-127.
  Память[регистр[d] + b] = popcnt(регистр[c]).

Пример:

```json
[
  {
    "op": "load_const",
    "b": 447,
    "c": 61
  },
  {
    "op": "read_mem",
    "b": 5,
    "c": 11
  }
]
```

### Классы

- `Assembler` - точка входа, разбор аргументов, вывод результата;
- `JsonParser` - разбор JSON (массив объектов со строками и целыми числами);
- `Translator` - превращает разобранный JSON в список `Command` и проверяет поля;
- `Command` - команда: операция и значения полей (внутреннее представление);
- `Opcode` - описание команд УВМ: название, код, размер, поля;
- `FieldSpec` - описание поля: имя, номер первого бита, ширина;
- `AssemblerException` - ошибка ассемблера.

## 3. Команды сборки и запуска тестов

Сборка и запуск ассемблера:

```
run_asm.bat tests\spec.json result.bin --test
bash run_asm.sh text/spec.json result.bin --test
```

Тесты:

```
tests\test_spec.bat
tests\test_errors.bat
```
